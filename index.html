About this Calculator

This tool implements the Advisor Commission Engine from the IndiaFirst Life Commission Master (Agency Channel, Top Product Rates effective 1 Nov 2025) and the BA Proposition earning constructs (Hiring, Earnings, Progression, MBG — Quarterly Design FY27 Q1, effective 1 May 2026, applicable for Individual BAs).

Every figure calculated here traces back to a rule in the source documents — expand "View Calculation Details" under any result to see the exact rate, slab and formula applied. Nothing is invented: where the source data was ambiguous (some Traditional/ULIP/Annuity product rows in the Commission Master), those products are intentionally left out of the live calculator rather than guessed at (see Reference tab).

Deploying on GitHub Pages

  1. Create a new GitHub repository (e.g. ba-calculator).
  2. Upload this index.html file to the repository root.
  3. Go to Settings → Pages, set Source to Deploy from a branch, branch main, folder / (root), then Save.
  4. Your calculator will be live at https://<your-username>.github.io/ba-calculator/ within a few minutes.

No build step, server, or dependency is required — this is a single static HTML file.
